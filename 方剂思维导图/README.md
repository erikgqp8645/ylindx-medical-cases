## 数据格式

每条方剂的脉舌记录包含：
- **脉象记载**：含「脉」字的原文（含 L-行号，可追溯到 full_transcript.md）
- **舌象记载**：含「舌」字的原文（含 L-行号）
- **案例标题**：涉及的医案标题列表

## 使用建议

1. **从方剂反查医案**：用主文件末尾"反查索引"找到分类
2. **从症状反查方剂**：用 Batch 文件里的脉舌记载（带 L-行号）
3. **方剂与原文对照**：行号引用可直接定位到 `full_transcript.md`
4. **可视化**：用 Mermaid 版文件，在支持 Mermaid 的编辑器中查看思维导图
