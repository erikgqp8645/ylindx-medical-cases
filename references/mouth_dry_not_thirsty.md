## 二、仲景经典原文(四处)

### 1. 《金匮要略·惊悸吐血下血胸满瘀血》— 瘀血总纲

> **病人胸满,唇痿舌青,口燥,但欲嗽水不欲咽,无寒热,脉微大来迟,腹不满,其人言我满,为有瘀血。**

**辨证要点**:`但欲嗽水不欲咽` — 水到嘴里润一下就吐,不咽。这是瘀血口渴最具特征性的表现,患者本能地觉得水咽不下去。

### 2. 《金匮要略·妇人杂病》(温经汤条) — 瘀血久留

> **问曰:妇人年五十所,病下利数十日不止,暮即发热,少腹里急,腹满,手掌烦热,唇口干燥,何也?师曰:此病属带下。何以故?曾经半产,瘀血在少腹不去,何以知之?其证唇口干燥,故知之。当以温经汤主之。**

**辨证要点**:唇口干燥 + 少腹急满 + 暮即发热 + 手掌烦热 = 瘀血久留,阴血被耗,虚实夹杂。

### 3. 《伤寒论》第73条 — 渴/不渴的关键鉴别

> **伤寒汗出而渴者,五苓散主之。不渴者茯苓甘草汤主之。**

【南极按:渴与不渴为重要区分点】(新冠后闭经案 line 213)

**辨证要点**:同样是「汗出 + 胃中停水」,渴者走膀胱气化不行(五苓散),不渴者仅是水停中焦(茯苓甘草汤)。口渴与否 = 津液能否上承 = 病位深浅的关键指标。

### 4. 《伤寒论》第156条 — 泻心汤与五苓散的口渴鉴别

> **本以下之故,心下痞,与泻心汤。痞不解。其人渴而口燥,烦,小便不利者,五苓散主之。**

**辨证要点**:同样是「心下痞」,渴而口燥 + 小便不利 = 水停下焦、气化不行,五苓散。临床意义:即便用了泻心汤痞不缓解,只要见到「渴而口燥 + 小便不利」,就要切换到五苓散思路。

### 5. 《温病条辨·下焦篇》(吴鞠通)

> **时欲漱口不欲咽,大便黑而易者,有瘀血也,犀角地黄汤主之。**

**辨证要点**:吴鞠通把仲景「但欲嗽水不欲咽」简化为「时欲漱口不欲咽」,加上「大便黑而易」= 瘀血下焦。犀角地黄汤主之。

### 病机 ① 瘀血阻滞,津液不行 — 医林独啸斋最强调

**核心病机**:瘀血占位 → 经络不通 → 津液无法正常敷布到口腔 → 主观「干」
**关键特征**:`但欲嗽水不欲咽` / `唇痿舌青` / 舌质紫暗 / 瘀血病史(外伤/手术/月经血块)

**对应经方**:
- **温经汤**(《金匮》)— 瘀血 + 阴血亏虚(唇口干燥 + 手掌烦热 + 少腹急满)
- **抵当汤**(《伤寒》)— 瘀血 + 喜忘 + 大便黑(阳明蓄血)
- **桂枝茯苓丸** — 瘀血 + 腹中癥块(妇科)
- **活络效灵丹**(张锡纯)— 瘀血阻络通用方

**代表方剂配伍思路(医林独啸斋实案)**:
- 当归建中汤专题 (line 720-810):桃核承气汤攻下瘀血 → 当归建中汤善后
- 食管癌75岁老人案 (line 345-395):柴胡桂枝汤 + 活络效灵丹 + 三才封髓丹
- 小伙子中邪案 (line 250-275):潜阳丹打底 + 抵当汤思路 + 郁金、丹参(瘀血精神疾患)
- 老胃病案 (line 630-680):桂枝茯苓丸 + 麦门冬汤 + 柴胡剂(瘀血 + 津液双补)

### 病机 ② 水湿内停,新水进不来 — 医林独啸斋明确并列

**核心病机**:水液代谢不及 → 废水排不出去 + 新水进不来 → 主观「干」但本能不欲饮(再喝加重湿滞)
**关键特征**:`渴不欲饮` / 腹胀 / 苔腻 / 舌胖 / 大便溏或黏

**对应经方**:
- **五苓散**(《伤寒》73/156条)— 渴而口燥 + 小便不利 + 心下痞(膀胱气化不行)
- **茯苓甘草汤**(《伤寒》73条)— 不渴 + 胃中停水(病位较浅,未阻津液敷布)
- **三仁汤**(《温病条辨》)— 湿温初起 + 头痛恶寒 + 身重疼痛 + 舌白不渴(湿重于热)
- **藿朴夏苓汤** — 湿温 + 身热不渴 + 肢体倦怠

**代表方剂配伍思路(医林独啸斋实案)**:
- 小儿反复高烧案 (line 1119):「中焦:寒湿困脾→湿热搏结(腹胀呃逆、渴不欲饮)」→ 三仁汤 / 五苓散
- 老胃病案 (line 644):同引瘀血条文,但论湿热致口干亦同此机
- 新冠后闭经案 (line 200-235):把仲景73/156条串讲为五苓散主证

### 病机 ③ 肺气不宣,气不化津 — 凉燥案关键发现

**核心病机**:肺气郁闭 → 宣发肃降失常 → 津液不布 → 口干但不欲饮(再喝水反而困脾)
**关键特征**:`口干不欲饮` + 鼻塞 / 咽干偶有稀痰 / 脉弦 / 舌淡暗稍胖、苔薄白但乏津样

**对应经方**:
- **杏苏散**(《温病条辨》)— 凉燥伤肺 + 头微痛 + 恶寒无汗 + 咳嗽稀痰
- **半夏厚朴汤 + 桔梗杏仁陈皮** — 痰湿咳嗽 + 肺气不宣
- **上焦宣痹汤** — 上焦湿热,肺气郁闭

**代表方剂配伍思路(医林独啸斋实案)**:
- 转被我误诊的秋季凉燥案 (line 243):「读此案才猛然发觉,乃肺气不宣、气不化津啊…」→ 杏苏散加味

### 病机 ④ 少阴阳虚,津不上承 — 麻附细打底

**核心病机**:肾阳虚衰 → 命门火不足 → 津液不化 → 干但不欲饮(再喝水反而停聚)
**关键特征**:`口干不欲饮水` + 但欲寐 + 怕冷 + 脉沉微 + 舌淡胖

**对应经方**:
- **麻黄附子细辛汤**(《伤寒》少阴篇)— 少阴表证 + 反发热 + 脉沉
- **真武汤** — 肾阳虚水泛 + 寒湿内停
- **四逆汤** — 纯阳虚,无表证

**代表方剂配伍思路(医林独啸斋实案)**:
- 孩子高烧且不恶寒案 评论区 (line 516):「口干不欲饮水,还但欲寐,显然得麻附细打底」

### 病机 ⑤ 虚劳津血不足 — 建中汤体系(对比参照)

**核心病机**:中焦虚损 + 化源不足 → 津血不生 → 咽干口燥(此为真正「渴」的对照面)
**关键特征**:`咽干口燥` + 手足烦热 + 悸 + 腹中痛 + 梦失精 + 舌淡红少苔

**对应经方**:
- **小建中汤**(《金匮》)— 虚劳里急 + 咽干口燥
- **黄芪建中汤** — 加虚劳自汗/盗汗
- **当归建中汤** — 加妇科血虚
- **归芪建中汤** — 气血双补

**代表方剂配伍思路(医林独啸斋实案)**:
- 62岁老人中耳炎流脓案 (line 935):小建中汤
- 产后虚弱案 (line 270):归芪建中汤
- 医林碎金录王琦 (line 462):引《千金》建中解读

**注意**:此病机的「口燥」是真正的津液亏虚,与前 4 个病机的「津液失布」本质相反。临床鉴别关键:此型「欲饮」(真渴),前 4 型「不欲饮」(假渴)。

**文章**:转被我误诊的秋季凉燥杏苏散效如桴鼓蒿芩清胆汤桔梗元玄汤上焦宣痹汤均无效
**行号**:line 230-275
**主诉**:复诊诉感冒,鼻塞、咽干偶有稀痰,**口干不欲饮**,脉弦,舌淡暗稍胖、苔薄白但乏津样
**处方**:杏苏散(杏仁/苏叶/前胡 + 二陈 + 桔梗/枳壳)→ 加厚朴 = 加味半夏厚朴汤
**学习要点**:这是医林独啸斋中明确提出「肺气不宣、气不化津」致口干不欲饮的代表性发现 — 患者读此案后才恍然大悟此前误用养阴清热无效的原因。

## 八、关键禁忌与注意事项

### 禁忌 1:不可见「口燥」即养阴

凉燥案(line 243)教训:此前学习赵绍琴先生经验,喜用此方化裁治疗咳嗽,但遇到「口干不欲饮 + 苔薄白但乏津样」时仍用养阴清热就错了 — 实际上是「肺气不宣、气不化津」,必须宣肺化湿。

### 禁忌 2:不可见「不渴」即利水

73 条对比:同样是「汗出 + 胃中停水」,不渴者用茯苓甘草汤而非五苓散 — 病位较浅,未阻津液敷布时,不可过用淡渗。

### 禁忌 3:瘀血型不可单纯养阴

建中汤专题(line 798):「莫名其妙的唇干口燥、不欲饮水是可以作为瘀血的指征之一」 — 必须先攻瘀或攻补兼施,单纯养阴只会越养越瘀。

### 禁忌 4:少阴型不可单用麻黄

孩子高烧案 评论区(line 512):少阴病 + 咽痛 + 舌淡胖大 + 人想睡觉恶寒怕冷 → 麻附细打底 + 真武汤/桂枝汤善后。单纯用麻黄发汗会致「太阳病发汗,遂漏不止」(伤寒 20 条)。

### 经典警示

> 「如果之前只能用改善形容,这个阶段那就是改善明显。(事后回忆这个阶段可以用日新月异来形容)。确诊前都不能吃大米饭,一吃大米饭就胃疼,现在尝试居然能顺利吃米饭了。」
> — 食管癌案 (line 376-385)
> 提示:口干不欲饮治愈后,患者饮食状态往往随之大幅改善,是疗效判定的重要指标。

## 十一、一句话核心心法

**「口燥不渴」= 津液失布,而非津液真亏 — 瘀血阻之、水湿停之、肺气/阳气不化之,皆可致此。仲景以「但欲嗽水不欲咽」一语点睛,医林独啸斋的曾荣修/王琦/吴鞠通体系皆承此义。临证当先辨「不欲饮」之机,再议活血/利水/温化,断不可一见口燥便投养阴。**
