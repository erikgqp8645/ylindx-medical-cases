> 「治疗带状疱疹一定要趁早,早治疗少受罪!

### 支柱① 瓜蒌红花汤+板蓝根+全蝎+蜈蚣
**出处**:邹孟城《三十年临证经验集·带状疱疹奇效方》(line 187-203)

```
瓜蒌红花汤(专病专方)
  全瓜蒌30-60g   ← 重用!重用!重用!(line 196-203)
  红花9g
  生甘草9g

加味:
  板蓝根15g      ← 邹孟城经验,未受西医处理者更佳
  全蝎9g         ← 搜剔瘀血+以毒攻毒保护神经
  蜈蚣3条        ← 同上
```

**邹孟城原文要点**(line 196-203):
- 「未几疱疹流行,余于数日内接治五、六人,无论症之轻重,皆以上方加板蓝根15g予服」
- 「轻者二、三日,重者四、五日,率皆痊可」
- 「**体质壮实者,瓜蒌用量宜适当加重,药后若轻泻一、二次,则见效尤速**」

**全蝎蜈蚣机理**(line 219-221):
1. 「**刺痛在中医看来属于瘀血,而虫类药物刚好可以搜剔瘀血**」
2. 「**全蝎蜈蚣携带的神经毒素对于无病之人是毒,在神经受损的患者身上反而可以起到以毒攻毒、保护神经的效果**」
3. 「古人经常用全蝎、蜈蚣处理痉挛抽搐性疾病,如抽风、痉病、破伤风等病,就是利用的其对神经系统的靶向性」(line 211)

### 支柱② 升麻鳖甲汤(从皮肤排毒)

**仲景原文**(line 335-337):
```
阳毒之为病:面赤斑斑如锦纹,咽喉痛,唾脓血。升麻鳖甲汤主之
阴毒之为病:面目青,身痛如被杖,咽喉痛。升麻鳖甲汤去雄黄蜀椒主之
```

**宋柏杉临床经验**(line 352-380):
- 「**阳毒相当于带状疱疹水疱期,皮肤一块红一块白的。这种情况下,我们就可以用升麻鳖甲汤**」
- 「如果是到了慢性期,疼痛很剧烈这种情况下,尤其老年人,就应该用**升麻鳖甲汤去雄黄、蜀椒汤**」
- 「如果疼痛剧烈,我们可以**合并麻黄附子细辛汤**」
- 「升麻鳖甲汤应该更好使,效果**远远超过龙胆泻肝汤和栝蒌红花汤的效果**」

**南极按**(line 388-408)的对比解析:
```
                瓜蒌红花汤        升麻鳖甲汤
药力方向         向下、向内        向上、向外
排毒通道         大肠              皮肤
机理           通便排毒          辛凉透表、托疹解毒
适用            实热、里实         表证、热毒外透
皮肤坚紧无汗者   不宜单用         合麻黄剂开毛孔排毒
```

七、误治陷阱
───────────────────────────────────────

### 陷阱①:套用龙胆泻肝汤
宋柏杉批评:「在好多文章里发现,带状疱疹经常用什么?龙胆泻肝汤。有一部分人用栝蒌红花汤,加点抗病毒的之类的银花、连翘,效果究竟怎么样?**肯定有效**。但是升麻鳖甲汤应该更好使」(line 368-376)

### 陷阱②:只看局部不调体质
医案1核心:「此方如果是不辨证的滥用,**基本不会有效果**。但是如果在辨证论治的基础上再加入此方,疗效就会大大提高!」(line 181)

### 陷阱③:忽视肾阳不足导致后遗痛
医案3关键发现:患者本已抓大部分病机,**但漏掉了肾阳不足**,南极补上真武汤才完美
→ 「**一般来说身体底子差、肾阳不足的患者,带状疱疹神经痛不容易痊愈**」(line 160)

### 陷阱④:瓜蒌与附子是反药?
明确破解:「瓜蒌与附子很多人都说他是反药。其实不是的,我合用的非常多,没有任何副作用的,不用担心」(line 168)
「**处方中有反药的时候,务必提前告知患者,以免抓药的时候产生误会**」(line 169)

### 陷阱⑤:大便秘结必须畅通
「**治疗带状疱疹的时候,大便必须通畅**。如果大便秘结,就要重用瓜蒌红花汤中的瓜蒌60-120g,服后只要腹泻了,病势就会被挫败」(line 161-162)
