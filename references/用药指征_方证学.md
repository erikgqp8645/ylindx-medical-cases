# 用药指征·方证学
> **医林独啸斋核心定位**:「指征」即「方证」,是判断「何时用这张方」的精确证据集合。
> 不是泛泛的「症状」,而是带 *病机*、*鉴别*、*抓手* 的精准指证。
> 语料库:456 篇 markdown,「方证」254 篇 + 「指征」111 篇 + 系统级「专题/解析」90 篇。

---

## 一、一句话核心心法

> 「**方证对应,指征为先。抓住抓手,辨证用方。**」
>
> 症状是表象,**指征** 才是「用这张方」的判断标准;**黄金指征** 是最精准、最不容忽视的核心证据。

---

## 二、「指征」与「方证」术语界定

「指征」与「方证」在医林独啸斋里是**同义但不同场合使用**的双层术语:

| 场合 | 用语 | 例 |
|---|---|---|
| 文章标题 / 章节名 | **指征** | 「升陷汤专题·解透大气下陷的**原理及指征**」 |
| 正文论证 | **方证** | 「此方**方证**为:气短不足以息、脉沉迟微弱关前尤甚」 |
| 标题强调精准 | **黄金指征** | 「平胃散的**黄金指征**:胃胀/嗝气/振水音/厚腻苔」 |
| 口语 / 经验 | **抓手** | 「抓住**阳气不足+阳气上浮**两个**抓手**」 |

**南极师原话** (升陷汤专题 L192-220):

> 「下面我会讲解大气下陷的具体**症候指征**。"
> 「这些就是大气下陷的**指征**。」

## 三、「指征」9 大维度模板

从 90 篇「专题/方证」文章抽出的标准化维度。每个方剂专题都按这个模板展开:

```
指征
├─ [1] 主诉/症状群      病人最痛/最难受的几个症状
├─ [2] 脉象             沉/浮/迟/数/滑/涩/弦/紧 + 关键脉位
├─ [3] 舌象             舌质(淡/红/暗/胖) + 舌苔(薄/厚/腻/剥)
├─ [4] 病机/抓手        一两句话的病机总结
├─ [5] 类证鉴别         与近义方剂的关键区别
├─ [6] 兼证             伴随症状(可有可无)
├─ [7] 舌底/腹诊        特殊诊法(瘀血脉、腹诊压痛)
├─ [8] 时间规律         夜间加重/阴雨加重/情绪相关
└─ [9] 治疗反应         服某方无效的鉴别方向
```

**南极师原话** (胃痛四合汤专题 L380-396,瘀血性胃病的指征):

```
瘀血性胃病的指征:
  1. 舌体有暗色瘀斑
  2. 舌头底部的血管粗大、扭曲、鼓包。舌底有明显瘀斑
  3. 胃部疼痛的位置保持不变,不会随意移动
  4. 胃部疼痛以针刺样疼痛为主
  5. 腹诊的发现胃部、小腹部有压痛、硬结
  6. 皮肤甲错,如同鱼鳞(此症候以小腿处为最常见)
  7. 疼痛夜间加重
  8. (女性)经期胃病加重
```

**黄金指征** vs **辅助指征** (腰疼三两半 L87-120):

> 「使用此方的时候,最重要的要点就是**抓住气分、血分的虚损**,同时**不应该有明显的水湿包裹腰部的病机**。"
> 「如果没有这些气分不足的**黄金指征**,还有别的症状可以诊察出气分不足的存在,**但是这些症候往往是多个病机都可以出现的,因此必须谨慎鉴别**」

## 五、临床实战流程(从症状到处方)

```
症状群
  │
  ├─ 抽提「黄金指征」(最精准、不可替代)
  │     ↓
  ├─ 列出「辅助指征」(多个病机共有)
  │     ↓
  ├─ 锁定「病机」(1-2 句话总结)
  │     ↓
  ├─ 候选 2-3 张方(类方鉴别)
  │     ↓
  ├─ 检查「禁忌指征」(用了会出问题的反向指征)
  │     ↓
  └─ 选定方剂 + 加减
```

**Pitfall**:
- 黄金指征 **必须出现**;辅助指征可叠加,但需鉴别
- 病机不明的「错杂型」,先看合方专题(如胃痛四合汤)
- 时间规律(夜间加重→瘀血;阴雨加重→寒湿;情绪相关→肝郁)是快速分流的捷径

## 八、关键术语速查

| 术语 | 含义 | 例 |
|---|---|---|
| **指征** | 「用这个方」的精准判断标准(同「方证」) | 「大气下陷的指征」 |
| **方证** | 同「指征」,正文论证里更常用 | 「平胃散方证」 |
| **黄金指征** | 最精准、不可替代的核心指征 | 「气分不足的黄金指征」 |
| **抓手** | 口语化,「判断切入点」 | 「抓住阳气不足+上浮两个抓手」 |
| **兼证** | 伴随症状,可有可无 | 「兼寒热往来、咽干作渴」 |
| **类证鉴别** | 近义方剂的关键区别点 | 「区别于结胸(按之痛)」 |
| **腹诊** | 日本汉方/经方常用的腹部触诊 | 「按之心下硬痛,手不可近」 |
| **舌底血管** | 舌下络脉,瘀血指征 | 「舌底血管粗大扭曲鼓包」 |
| **时间规律** | 加重时间作为分流捷径 | 「夜间加重→瘀血」 |
