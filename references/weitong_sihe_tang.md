# 「胃痛四合汤」专题 — 焦树德四十年经验合方体系

> 与 `references/blood_stasis_formulas.md`(瘀血方剂总论)、`references/all_yuxue_fangji.md`(35 方活血化瘀全集)对偶互补 —— 本专题聚焦 **胃病领域内** 寒热燥湿瘀四种病机错杂的合方体系,与广谱祛瘀方互补;共享失笑散、丹参饮、金铃子散等基础方。

═══════════════════════════
一、方剂来源与定位
═══════════════════════════

**焦树德**(《方剂心得十讲·第10讲·焦树德经验方》)「胃痛四合汤」= 焦老 40 多年临床经验集合体,核心特点:**把类似功效的方剂融合在一起,极大地提升疗效**。原文:

> 「胃痛四合汤是焦树德老先生 40 多年经验的集合体,其疗效卓著、适应症广泛,可以应对很多病机复杂的胃病,实在是不可多得的良方」(line 25)

**关键判断 —— 此方适合处理错杂型症候**:

> 「这种病机单一的疾病,都绝对不适合使用胃痛四合汤。此方适合处理的是错杂型的症候」(line 263)

病机属 **寒热错杂、燥湿错杂、伴随淤血**,适用对象一般都是胃病多年、绵延不愈的患者(line 280)。

三、焦树德原方与方证(权威出处)
═══════════════════════════

**胃痛三合汤**(《方剂心得十讲·第10讲·焦树德经验方》line 63):

```
高良姜 6-10g   制香附 6-10g
百合   30g     乌药    12g
丹参   30g     檀香   6g(后下)   砂仁 3g
```

**胃痛四合汤**(line 115,= 胃痛三合汤 + 失笑散):

```
高良姜 6-10g   制香附 6-10g
百合   30g     乌药    12g
丹参   30g     檀香   6g(后下)   砂仁 3g
五灵脂 9-12g   蒲黄   6-10g(包煎)
```

**三合汤方证(line 67-73)**:
1. 长期难愈的胃脘痛,或曾服用其他治胃痛药无效者
2. 舌苔白或薄白,脉象弦或沉细弦,或细滑略弦,胃脘喜暖,**痛处喜按,但又不能重按**,大便或干或溏,**虚实寒热症状夹杂并见** 者
3. 可包括西医学各种慢性胃炎(浅表性、萎缩性、肥厚性),胃及十二指肠球部溃疡、胃粘膜脱垂、胃神经官能症以及胃癌等所致的胃痛

**四合汤方证(line 119)**:
> 「主治同三合汤证,但又兼有 **胃脘刺痛,痛处固定,唇舌色暗或有瘀斑,或夜间痛重**,脉象沉而带弦。」

四、南极按:药简力专 vs 多方联用(关键心法)
═══════════════════════════

南极师在 line 195-280 反复强调一个核心原则——「**合方不会打架,关键是病机错杂**」:

1. **处方必须与病机对应,丝丝入扣**(line 237)
2. **假如一对相反的病机同时出现在一个人体内,病机表现出错杂之势头 —— 寒热错杂、燥湿混杂甚至阴阳混杂。那么必须开出错杂的方剂,以错杂之方剂解除错杂之病机。不管这个合方多么奇葩,也要咬着牙开出来**(line 241-242)

> 「比如我曾经开出过大青龙加附子汤、四逆汤合白虎汤等非常奇葩的合方。这些奇葩方子开出去的时候,心里头觉得又别扭又难受,跟吃了苍蝇似的。但是反馈疗效又出奇的好。可见人体之奇妙,不可以等闲视之」(line 246-247)

**关键判断(病机单一绝对不可用四合汤)**:

- 纯寒性胃痛 → 良附丸、小建中汤、大建中汤、附子理中汤、李东垣厚朴温中汤等;再掺杂益胃汤、百合乌药汤等甘寒滋润剂,**反而令病情急剧变坏**(line 255)
- 纯胃阴虚 → 重用甘寒滋润药;夹杂辛温,**必然加重**(line 259)
- 类比仲景半夏泻心汤(line 267)→ 寒热错杂的半夏泻心汤证与胃痛四合汤同源同理

───────────────────────────
5.1 良附丸(《良方集腋·卷上·气痹门》)
───────────────────────────

**原方**:高良姜(酒洗七次,焙研)、香附子(醋洗七次,焙研)各等分

**焦树德强调的煎服法**:「上二味,须要各焙、各研、各贮,否则无效」(line 440)

**剂量随病机调整**(line 444-450):
- 病因寒而得 → 高良姜二钱,香附末一钱
- 病因怒而得 → 高良姜一钱,香附末二钱
- 寒怒兼有 → 各一钱五分

**病机**:胃寒 + 腹中气机不畅(line 456)

**寒性胃病指征**(line 464-478):
1. 口中寡淡无味
2. 口中寡淡加重时欲呕
3. 口中常有清稀之唾液源源不断分泌
4. 吃冷食或寒凉中药后胃痛加重,甚至腹泻
5. 心口、胃部、胃部正对着的背部发冷、怕冷风吹
6. 肚子稍微被冷到就胃痛、腹泻

**与寒疝的关系**:「对于寒性胃痛、腹痛,可以参考古籍中的 **寒疝** 症候去理解」(line 488)

───────────────────────────
5.2 百合汤(《时方歌括·卷下》,为辨识度常称「百合乌药汤」)
───────────────────────────

**原方**:百合一两,乌药三钱

**陈修园方歌**:「久痛原来郁气凝,若投辛热痛频增,重需百合轻清品,乌药同煎亦准纯」(line 530)

**陈修园批注**:「此方余从海坛得来,用之多验」(line 542)

**关键 —— 百合重用 30g 是本方灵魂**(line 546-550):

> 「此方中百合是绝对的主导,重用到 30g,是本方的灵魂所在。焦树德老先生的胃痛三合汤、胃痛四合汤都遵守此规律,百合剂量都保持在 30g 不变」

**方证解析**(line 554-574):
- 胃痛寒热均可存在,投以辛温止痛药物,疼痛反而增加 → 必然不是纯粹寒证(可能是寒热错杂,或热证被误认为寒证)
- 百合甘寒糯润 → 被灼伤的胃部黏膜得到滋养,自然宽舒适
- **重要边界**:若 **纯粹** 是胃部阴液不足导致的胃痛,**只需要甘寒糯润法就够了**,再加运转气机的药物反而画蛇添足
- 南极曾 **纯用益胃汤治愈过此类胃痛**(line 566)

**方剂本质 —— 不只是方子,是法度**:

> 「百合乌药汤这一个小小的方剂,本质上是 **甘寒润津液法+辛苦温行气法** 的叠加」

> 「百合乌药汤不只是一个方子,更是一个法度,把 **甘寒的麦冬、百合、玉竹、生地** 与 **辛燥苦温行气的乌药、砂仁、木香** 等药物有机结合,可以推导出无数的新方剂」(line 574-579)

**百合乌药汤使用指征**(line 585-596):
1. 舌质干燥、咽喉发干,总想喝水滋润(甚至鼻孔、眼睛也干燥)
2. 舌面无苔或苔少,舌体可红可淡红
3. 胃中有灼热感,吃梨子等水汁充足的水果觉得舒适
4. 服用纯粹温热止痛药后疼痛立刻加重,或先舒适一段时间后加重
5. 服用纯粹甘寒方剂(如益胃汤)后胃痛缓解,但觉得胃胀、腹胀、窒闷感

5.3 丹参饮(《时方歌括·卷下》)
───────────────────────────

**原方**:丹参一两,檀香砂仁各一钱(line 314)

**陈修园方歌**:「心腹诸疼有妙方,丹参十分作提纲,檀砂一分聊为佐,入咽咸知效验彰」(line 310)

**陈修园批注**:「稳」(line 322)

**关键 —— 丹参为绝对主导,必须 30g 起步**(line 326-331):

> 「此方以丹参为绝对的主导,使用的时候必须用到 30g 甚至更多。丹参有着非常强大的祛瘀血能力,胸中、肋部、腹部的淤血他都可以搞定。治疗肝病等以肋痛为主的疾病的时候,我最爱用的就是大剂量丹参了,祛瘀血止痛的效果非常优秀。**30g 起步,60g 亦不为多**!」

**方证**:**「治心痛胃脘诸痛多效。妇人更效」**(line 308)

8.1 联用金铃子散 → 「胃痛五合汤」(line 619)
───────────────────────────

金铃子散(《时方歌括》):
- 川楝子(金铃子)—— 苦寒,引心包相火下行,从小肠膀胱而出
- 延胡索 —— 和一身上下诸痛
- 用法:研末,以清酒调服三钱(line 641)

**陈修园原批注**:

> 「金铃子散妙如神,须辨诸疼作止频(火痛或作或止)。胡索金铃调酒下,制方原是远温辛」(line 641)

**陈修园总结三方**(line 670):

> 「以上三方【金铃子散、丹参饮、百合乌药汤】,皆治心胃诸痛,**服热药而不效者宜之**」

> 「古人治痛,俱用通法。然通之之法,各有不同。调气以和血,调血以和气,通也。上逆者使之下行,中结者使之旁达,亦通也。虚者助之使通,寒者温之使通,无非通之之法也。若必以下泄为通,则妄矣。」

**南极补充**(line 656-657):
- 川楝子一般用 **3-15g**,根据热的大小调整;剂量再大会很难吃,胃也受不了
- 延胡索「剂量稍微大点,疗效才明显。**对于剧烈的腹中、胸中疼痛,重用 30g 往往可以一剂定痛**」

8.2 联用柴胡剂(line 717-738)

安中散(《太平惠民和剂局方·治一切气》):

**原方组成**:延胡索(去皮)、良姜(炒)、干姜(炮)、茴香(炒)、肉桂各五两,牡蛎(煅)四两,甘草(炒)十两

**方证**(line 761):
> 「治远年、日近脾疼翻胃,口吐酸水,寒邪之气留滞于内,停积不消,胸膈胀满,攻刺腹胁,恶心呕逆,面黄肌瘦,四肢倦怠。又治妇人血气刺痛,小腹连腰攻注重痛,并能治之」

**关键 —— 安中散 ≈ 良附丸的扩充**:

> 「此方以暖胃为主,同时有着良好的制酸的能力,胃寒腹痛伴随反酸烧心的患者,以此方常常有良效。此方相当于胃痛四合汤中良附丸的扩充」(line 774-778)

**临床策略(动态联用)**:

1. 当寒证明显 → **先去掉百合乌药汤,合方安中散**。如果直接治愈,自然不错(line 782)
2. 倘若服药一段时间胃痛减轻,然而 **微微口干,胃中津液略有不足的时候** → **再去掉安中散,并把百合乌药汤『请』回来**(line 786)
3. 如此一来,胃部寒热调和、津液恢复,自然正常(line 790)
