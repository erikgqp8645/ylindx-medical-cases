# 附子·方证学

> **医林独啸斋核心定位**:附子不是「温阳药」这么简单,而是「阳气不足」+「阳气外泄」+「阳气拔根」三联病机的针对性用药。
>
> 语料库:456 篇 markdown,**216 篇含附子**(47%)。「方证/指征/抓手/舌象/脉象」覆盖阳虚外感、上热下寒、虚火上浮、阳虚湿盛、阳虚痹痛、大病后阳气未复 6 大场景。

---

## 一、一句话核心心法

> 「**阳虚则用之,阳浮则潜之,阳越则挽之;舌淡胖润为常,舌尖红则兼上热;尺脉不足、舌根凹陷为肾阳不固之铁证。**」

---

## 二、附子适用三联病机(总纲)

```
附子适用证
├─ [A] 阳气不足    → 整体偏寒(舌淡/怕冷/精神倦怠/嗜睡)
├─ [B] 阳气上浮    → 上部虚火(牙痛/口疮/出血/烘热/舌尖红)
└─ [C] 阳气拔根    → 肾阳外泄(脉时浮时沉时数时细/高烧无汗/两足冰冷)
```

**南极师原话**(潜阳丹专题 L152):
> 「使用此方的时候,只需要抓住 **阳气不足+阳气上浮** 这两个抓手」

**南极师原话**(大青龙加附子汤 L353):
> 「脉时浮时沉时数时细者,**下焦无阳,中气失根,不能安定也**。」

**彭子益原话**(肾气丸法 L583):
> 「脉弱而散者,**肾阳外散,中气无源**。肾阳外散,则心神失根,中气无源,则脉息不振也。」

| **舌淡,边有齿痕,舌苔白腻** | 近效�附汤 L482 | 阳虚+水湿 |
| **舌淡润胖大** | 近效朮附汤 L395 | 肾元不足+水湿 |

### 3.2 上热下寒舌(大青龙加附子汤 L213)

**南极师原话:**
> 「本方证的常见舌象,往往是 **舌尖红、舌头后部淡白**,提示上热下寒。」

```
上热下寒舌
├─ 舌尖 → 红(上焦/中焦有热)
├─ 舌中 → 看脾胃(凹陷=虚,隆起=实)
└─ 舌根/后部 → 淡白(下焦肾阳不足)
```

### 3.3 胖大齿痕舌(水湿舌,近效朮附汤 L98/524)

| 舌象特征 | 出处 |
|---|---|
| 舌体胖大湿腻 | 近效朮附汤 L98 |
| 胖大齿痕 + 舌苔白腻 | 近效朮附汤 L524(「水湿舌」) |

### 3.4 凹陷舌(肾气丸法 L707)

**南极师原话(肾气丸法 L707):**
> 「肾气丸指证有:**舌根部位有明显凹陷**。舌根部位有明显凹陷,按着没啥内容物。」

```
凹陷舌(肾精不足)
├─ 舌根凹陷 → 肾精不足 → 肾气丸(附子 + 熟地)
└─ 舌尖凹陷 → 心肺不足 → 其他方
```

### 3.5 紫斑/暗舌(特殊情况)

| 舌象特征 | 出处 |
|---|---|
| **舌质赤,苔薄白**(兼紫色瘀斑) | 大青龙加附子汤 L487(两感于寒重症) |
| 舌头中部有少量瘀斑 | 退烧后喝冷饮案 L95(阳虚+瘀血) |

## 四、脉象速查(5 类核心脉)

### 4.1 尺脉不足(肾阳虚铁证)

**南极师原话**(肾气丸法 L447):
> 「尺脉不足,**缺乏底力,按着没啥内容物**。」

```
尺脉诊断法
├─ 尺脉按之没有底力 → 肾阳不足
├─ 尺脉极度虚弱、下肢冷如冰 → 典型下焦肾阳不足
└─ 尺脉如按棉花状 → 严重肾气虚
```

### 4.2 脉时浮时沉时数时细(两感于寒)

**彭子益原话**(肾气丸法 L591):
> 「脉时浮时沉时数时细者,下焦无阳,中气失根,不能安定也。」

适用:大青龙加附子汤证(表寒+肾阳虚共存)。

### 4.3 沉细弱/沉细无力(少阴病主脉)

**南极师原话**(孩子高烧不恶寒 L264):
> 「似乎剧烈恶寒的患者比较少,很多都只是精神极度倦怠、舌头淡白、皮肤干燥无汗。」
> 「脉象可以是 **沉细无力**,也可见 **脉象浮大无根、且边缘模糊**。」

### 4.4 右关脉宽厚有力(中焦胃热)

**大青龙加附子汤 L124:**
> 「右关脉比右寸尺宽厚有力的时候」(中焦胃热,需要石膏)

### 4.5 脉兼弦(肝气不舒/水湿)

**大青龙加附子汤 L152:**
> 「脉象兼弦的时候」(附子 + 疏肝药)

## 六、附子与石膏并用(冰火两重天)

**南极师原话**(新冠大白肺 L491):
> 「大家一定要学会 **附子石膏并用法**!这样可以救治很多人!」

**机制:**
- 附子 → 温下焦肾阳,振奋机能
- 石膏 → 清上焦肺热,生津止渴
- 同时用 → 上下同调,适合「上热下寒」+「表里两感」

**适用场景:**
- 高烧 + 舌淡(肾阳虚) + 口干舌燥(中焦热)
- 附子用小量,石膏可用大量
- 服后效果:下肢逐步发热温暖,口中不再燥渴,体温慢慢下降

**代表医案:** 甲流高烧 39℃瘫软在床,附子石膏并用而痊

## 七、应用禁忌(Pitfall)

1. **没有明显肾阳不足时**(大青龙加附子汤 L413) — 不应使用此方,「下焦肾阳不足为本方前提」
2. **中焦脾胃极端虚弱**(大青龙加附子汤 L413) — 单用炙甘草不够,需「像再造散一样加入人参强力健胃」
3. **附子、半夏、瓜蒌同用没问题**(新冠大白肺 L407) — 药房瞎改方子的不要听
4. **附子煮时不能加冷水**(退烧后喝冷饮 L303) — 必须先煎附子 30 分钟
5. **附子发麻不一定是中毒**(退烧后喝冷饮 L329) — 瞑眩反应,需观察后续
6. **孩子高烧不恶寒也可用附子**(孩子高烧案 L264) — 精神极度倦怠+舌淡白+皮肤干燥无汗即可
7. **附子证发热可超过 39℃**(肾气丸法 L336) — 「附子证的发热高烧、低烧均可以存在」

## 八、附子使用 4 大要点(实战总结)

### 8.1 剂量与煎煮
- **常规剂量:** 3-30 g(根据场景)
- **必须先煎 30 分钟**(退烧后喝冷饮 L303)
- **煮时不可加冷水**

### 8.2 与他药配伍核心
- **附子 + 石膏** = 冰火两重天(上热下寒)
- **附子 + 熟地** = 肾气丸法(肾阳+肾精双补)
- **附子 + 人参** = 参附汤(中焦+下焦双补,新冠大白肺 L149)
- **附子 + 白术** = 术附汤(阳虚湿盛)
- **附子 + 麻黄细辛** = 麻附辛(阳虚外感)
- **附子 + 半夏/瓜蒌** = 没问题,药房瞎改方子不要听(L407)

### 8.3 瞑眩反应识别
- **附子剂服后口舌发麻 + 病痛减轻** = 瞑眩反应,继续吃
- **附子剂服后口舌发麻 + 病痛未减** = 警惕中毒
- **附子剂服后全身发热但无麻木** = 阳虚重,药力被吸收(L413)

### 8.4 不熟悉者慎用
**南极师原话**(肾气丸法 L729):
> 「南极老师最后的提醒特别到位:**不熟悉的人不要用**。」
