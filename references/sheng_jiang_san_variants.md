# 升降散 变法·医案·处方汇编

> 与 references/stagnant_heat_yure.md(郁热病机专题)对偶:
> 本文件按"处方变法"组织,聚焦"具体怎么改方",而非"为什么用升降散"。
> 病机逻辑请参见 stagnant_heat_yure.md。

## 原方与核心心法

杨栗山《伤寒温疫条辨》原方:蝉蜕 僵蚕 片姜黄 大黄

南极师核心论断(贯穿全文):
> "升降散是一张表里分消热邪的处方,
> 从皮肤(蝉蜕)与大肠(大黄)两条通路排出体内的热毒。"

> "热邪本就有向上向外漂浮的势头,
> 所以就用辛凉药物,顺着这个势头就把体内的热邪从肌表透散出去。"
> ——武术中的"借力打力"

## 医林独啸斋核心定位(原话引用)

**关于去大黄的判断**(全文最常用原则):
> "使用升降散的时候,如果阳明大肠是通畅的
> (即没有便秘、大便排解不畅等情况),就要去掉大黄。
> 用了大黄反而伤脾胃,大便溏泄不止。"

**关于大黄剂量(小儿)**:
> "生大黄1克(必须称准,同煎,不用后下)"
> ——小儿严格控量,不后下取缓下之意

**关于姜黄替换**(南极回复读者):
> "姜黄太苦不用就是了,排脓散换换也没啥,
> 只要大思路是正确的,辩证对了,怎么都能治好。
> 至于资生丸,不带考虑的,看着高大上、实则无效之方。"

**关于僵蚕替代**(过敏体质):
> "大约1%的概率会遇到僵蚕过敏的患儿,
> 去掉了就不过敏一样有效了。
> 所以现在过敏体质用僵蚕我只能搭配徐长卿一起了。"

**关于辛凉-辛温借力打力**:
> "温病退烧所得之汗,乃是郁热外散之汗。
> 如果不能够看明白这一点的话,
> 就无法理解为什么用这么轻的药物,竟能让人出这么透的汗。"
> ——见高烧39刀片嗓葱豉升降散案

## 一、保留整方(不动原方四味)
──────────────────────────────────────────────────

### 变法[1] 柴胡升降散 = 小柴胡汤 + 升降散

出处:
- 柴胡升降散专题:女孩新冠高烧40℃三剂退热
- 流感高烧39.2℃柴葛升降散一剂退烧两剂痊愈

处方(柴胡升降散原方):
```
北柴胡40  黄芩15  半夏15  太子参15
炙甘草15  生姜4片  大枣5枚切开
蝉蜕12   炒僵蚕12  姜黄12  生大黄6
```

复诊降大黄:
> "高烧已经退下,大便也通快。大黄剂量可以降低了。"
> ——大黄减至2g

核心逻辑:
> "升降散是一张表里分消热邪的处方,
> 从皮肤(表)与大肠(里)两条通路排出体内的热毒。
> 在这个过程中,因此我经常把柴胡剂与升降散联用,
> 发现疗效显著提升!
> 这应该是因为柴胡剂斡旋枢机的能力与升降散的特性相互融合的结果。"

### 变法[2] 柴葛升降散 = 葛根汤 + 小柴胡 + 升降散 + 牛蒡子

出处:流感高烧39.2℃柴葛升降散一剂退烧两剂痊愈

处方:
```
葛根45  麻黄9  桂枝6  白芍6  炙甘草6
生姜4片  大枣4粒
北柴胡24  黄芩15  半夏9  党参9
蝉蜕9   姜黄9   僵蚕9   大黄6
牛蒡子15  ←利咽喉
```

按语:
> "合方升降散是因为患者体内憋了一堆热邪,
> 此方的蝉蜕向上向外、外透热邪,
> 大黄向里向内、内消热邪。"
> "葛根汤对于眼眶、眼球、额头部位的疼痛有特效。"

### 变法[3] 大柴胡汤 + 升降散 + 五味消毒饮

出处:甲状腺炎淋巴结炎红肿化脓剧痛彻夜哭喊,纯中药治愈

处方:
```
北柴胡18  黄芩9  半夏9  枳壳9  生白芍9
生姜5片  大枣5枚切开
生大黄6  蝉蜕15  炒僵蚕9  姜黄9
野菊花9  金银花15  蒲公英15  紫背天葵9
丹参30  生薏苡仁60  焦三仙各12
```

逻辑:
> "升降散(蝉蜕、僵蚕、姜黄、大黄)可以
> 从肌表与大便两条路径排出体内的热毒,给热邪找出路。"

## 二、姜黄的替换:郁金代姜黄
──────────────────────────────────────────────────

### 变法[4] 郁金代片姜黄(姜黄太苦 / 湿邪重)

代表案例:
- 成人水痘嘴巴喉咙都长
- 宣透郁热后咳嗽加重了不那是快好了(3岁孩子)
- 小朋友积热咳嗽(赵绍琴宣透郁热法一剂愈)
- 高烧39三天刀片嗓葱豉升降散
- 小孩鼻甲肥厚反复咳嗽支原体感染五次(两诊方都用)

代表处方(成人水痘案):
```
蝉蜕15  炒僵蚕9  郁金9  牛蒡子9  淡豆豉12
——升降散去姜黄、大黄,再加宣散郁热药物
```

原文按语:
> "由于本患者的大肠腑气是通的,
> 并没有使用大黄的机会。
> 所以去掉大黄,并用郁金替换片姜黄。"

### 变法[5] 升降散 + 水红花子(赵绍琴化瘀法)

出处:小女孩斜视半年
处方片段:
```
蝉蜕9  炒僵蚕9  姜黄6  水红花子9
——升降散去大黄,加水红花子,
   这是赵绍琴老先生常见的加减法
```

## 三、大黄的多重替换(按病机分)
──────────────────────────────────────────────────

### 变法[6] 蚕砂代大黄(胃不和、腹胀欲吐)

出处:小孩疱疹性咽峡炎11天没好透反复高烧40

处方片段:
> "由于孩子腹泻,所以我将升降散中的大黄去掉,
> 换成蚕砂。蚕砂亦是治疗小儿呕吐、腹泻、发热的良药。"
```
蝉蜕15(打碎)  炒僵蚕9  姜黄6  蚕砂9
生薏苡仁30  苦杏仁15  白蔻仁6  滑石18
```

同类案例:小孩发烧燥热口渴欲呕(升降散与三豆饮完美配合)
> "由于孩子有腹胀、恶心想吐、肚子不舒服等胃不和的表现,
> 因此我加蚕砂来替换大黄,来调节消化道、和胃止呕。"

### 变法[7] 淡豆豉代大黄(消化道症状 + 无便秘)

出处:小儿反复高烧39℃四天,一张遭人骂的方子覆杯而愈

处方片段:
```
蝉蜕18(打碎)  炒僵蚕9  姜黄6  淡豆豉9
——升降散,豆豉替换大黄。豆豉是多面手,
   既可以消除胃肠积滞,又可以宣透郁热
```

解读:把降浊的功能换成"宣透 + 消食"双效。

### 变法[8] 芦根/白茅根代大黄(赵绍琴经典用法)

代表案例:
- 宣透郁热后咳嗽加重了不那是快好了
- 小孩发烧燥热口渴欲呕
- 小女孩剧烈咳喘憋闷两个月(从尿排毒)

处方:
```
蝉蜕6  炒僵蚕6  郁金6  芦根15  白茅根15
——升降散,去大黄,以郁金代姜黄,
   再加芦茅根,这是最常见的宣透郁热加减法
```

赵绍琴原话:
> "升降散打底,去大黄,再加芦茅根,
> 用这个治疗严重的温病。"
> (原方从尿排毒而非大便排毒,治温病更平稳)

### 变法[9] 全瓜蒌+浙贝代大黄(降痰防咳)

出处:高烧39三天刀片嗓咽喉红肿(2诊方)

处方:
> "将大黄之降降级为瓜蒌、浙贝之降,
> 不仅更加轻灵,而且能防止患者产生咳嗽咳痰的问题,
> 提前截断,防止疾病传变,免除患者咳嗽之苦。"
```
全瓜蒌12  苦杏仁12  浙贝母12
——化痰、降下痰邪(替换掉升降散中的大黄)
```

### 变法[10] 莱菔子代大黄(降食积)

出处:打怪升级第一关(读者评论)
> "小柴胡汤合升降散(去大黄加莱菔子)合苇茎汤
> 加浙贝、杏仁加焦三仙"

### 变法[11] 焦三仙代大黄(治热之源)

出处:小孩长期脚面浮肿,宣透郁热法治愈(脉案)
```
蝉蜕9  片姜黄6  僵蚕10  佩兰10  大腹皮10
槟榔10  焦三仙各10  川楝子6  瓜蒌15  桃仁15
芦根15  水红花子10  大黄5  滑石24  白术10
荆芥9  防风9
——保留少量大黄5g + 焦三仙(治热之源)
```

### 变法[12] 大黄减量 + 同煎不后下(防苦寒伤胃)

处方:宝宝发烧流黄稠涕剧烈咳嗽腹灼热
```
生大黄1克(必须称准,同煎,不用后下)
——用于小儿时严格控量,不后下取缓下之意
```

## 四、僵蚕/姜黄的简化版

### 变法[16] 单用蝉蜕(去掉僵蚕,过敏体质备用)

出处:小朋友积热咳嗽(评论区)
> "现在比较头疼大约1%的概率会遇到僵蚕过敏的患儿,
> 去掉了就不过敏一样有效了。
> 所以现在过敏体质用僵蚕我只能搭配徐长卿一起了。"

同类:甲状腺炎淋巴结炎案
> "在19号减了2个药的基础上,去蝉蜕,加僵蚕。黄芩加到9。"

### 变法[17] 蝉蜕+淡豆豉(去掉僵蚕+姜黄+大黄,治小儿)

出处:5岁小儿荨麻疹案
> "蝉蜕9(打碎)  青蒿12  荆芥3  防风3  苏叶3
> ——辛凉远大于辛温,这是重点。
> 淡豆豉9  生鸡内金12
> ——淡豆豉多面手,既可以辛凉散热,
>    又可以与鸡内金一起消化食积"

解读:脾胃虚弱小儿,淡豆豉代僵蚕+姜黄,
鸡内金代大黄,以食积消解代替寒下。

### 变法[18] 蝉蜕+僵蚕+木蝴蝶+桑叶(轻灵透热版)

出处:小朋友积热咳嗽(赵绍琴宣透郁热法一剂愈)

```
苦杏仁9  焦三仙各9  桑叶9  枇杷叶6
```

按语:
> "赵绍琴老中医用的清灵宣透之法,核心是运用了
> 清代杨栗山的升降散,该方由蝉蜕、僵蚕、片姜黄、大黄组成,
> 方中根据患儿实际症状,去掉了片姜黄、大黄,
> 以桑叶、木蝴蝶代替。"
> ——轻灵透热,适合小儿积热咳嗽
